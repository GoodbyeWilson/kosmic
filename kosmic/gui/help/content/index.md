# KOSMIC

KOSMIC is a desktop application for analysing single-cell and
single-nucleus RNA-sequencing (scRNA-seq and snRNA-seq) data.

It is built around a simple fact: for most tissues and diseases, the
data already exist. Thousands of scRNA-seq and snRNA-seq datasets have
been published and deposited in public repositories such as GEO, each
containing gene-expression measurements from thousands of individual
cells or nuclei. KOSMIC lets you take such a dataset — published by
someone else, or generated by you — and analyse it for your own
question: which cell populations it contains, which genes and
pathways differ between conditions in the cell type you care about,
and what that looks like as a publication-ready figure.

Because a question is usually addressed by more than one published
dataset, KOSMIC can also bring together results from several
independent studies. This allows you to ask whether the same genes,
pathways or cell types show consistent changes across different
datasets, rather than relying on the result of a single experiment.

No programming is required. Each part of the analysis is performed
through a graphical workspace, where you choose the data, review the
results and adjust the relevant analysis settings. KOSMIC records these
settings as you work and can use them to generate a description of the
methods used in your analysis.

The name stands for *Kirk's Open-source Single-cell Meta-analysis
Integration and Comparison*.

## The basic idea

A KOSMIC **project** contains one or more **studies**.

A study represents a single scRNA-seq or snRNA-seq dataset — for
example, a published human brain snRNA-seq study containing cells from
people with Alzheimer's disease and unaffected donors.

For each study, KOSMIC can take you through the main stages of
single-cell analysis:

> Expression data → quality control → cell clustering → cell-type
> identification → differential expression → pathway analysis

If your project contains several comparable studies, KOSMIC can then
combine their results:

> Study 1 + Study 2 + Study 3 → meta-analysis → genes and pathways that
> change consistently across studies

KOSMIC can also create a **shared cell atlas** from several datasets.
Instead of identifying cell types separately in every study, the
datasets can be analysed together to establish a common set of cell
populations. These labels can then be transferred back to the
individual studies, making comparisons between them more consistent.

## What can I do with KOSMIC?

### Analyse a single scRNA-seq or snRNA-seq dataset

You can import an existing single-cell or single-nucleus
gene-expression dataset into KOSMIC. This may be a dataset you
generated yourself or one obtained from a public repository such as
GEO.

KOSMIC accepts common single-cell data formats, including `.h5ad`
files, Seurat objects, 10x Genomics outputs and count matrices.

Once imported, KOSMIC guides you through the steps needed to turn the
expression matrix into biologically meaningful cell populations. You
can remove poor-quality cells and likely doublets, normalise the
expression data, reduce its dimensionality, identify clusters of
similar cells and assign biological cell-type labels to those clusters.

After cell types have been identified, you can select a population of
interest — for example, endothelial cells — and compare gene expression
between two experimental groups, such as disease and control.

KOSMIC performs this comparison using pseudobulk differential
expression, where cells from each biological donor are combined and the
donors, rather than individual cells, are treated as the independent
biological replicates.

The resulting genes can then be investigated using gene-set, pathway
and enrichment analyses.

These analyses are performed primarily in the
[scRNA Analysis](scrna/index.md) and
[Differential Expression](de/index.md) workspaces.

### Compare results across several studies

A biological question is often addressed by more than one published
scRNA-seq or snRNA-seq dataset.

For example, you may have identified four studies containing
endothelial cells from people with the same disease and suitable
control donors. Each study can first be analysed independently in
KOSMIC.

KOSMIC can then combine the differential-expression results from those
studies using meta-analysis.

Rather than simply merging all of the cells into one experiment,
KOSMIC retains the individual studies and asks whether their results
provide consistent evidence for a change. This can help identify genes
and biological pathways that are reproducibly altered across
independent datasets.

This analysis is performed in the [Meta-Analysis](meta/index.md)
workspace.

### Build a shared cell-type atlas

Different studies may describe or annotate their cell populations
differently. One dataset might, for example, divide endothelial cells
into several subtypes while another uses a single endothelial-cell
label.

KOSMIC therefore provides the option to build a shared atlas from the
datasets in a project. The datasets are brought together, cell
populations are identified and annotated using a common analysis, and
those shared cell-type labels are then transferred back to the
individual studies.

This provides a consistent cell-type framework for subsequent
comparisons and meta-analysis. See [Shared atlas](project/atlas.md).

## How KOSMIC is organised

Everything begins with a **Project**.

A project is the container for a biological question or analysis.
Within the project, each independent scRNA-seq or snRNA-seq dataset is
added as a separate **study**.

For example, a project investigating vascular changes in Alzheimer's
disease might contain:

- Study 1 — human brain snRNA-seq dataset from one publication
- Study 2 — human brain snRNA-seq dataset from a second publication
- Study 3 — human brain scRNA-seq dataset from a third publication

The [Project workspace](project/index.md) shows these studies together
and records how far each has progressed through the analysis.

From there, the main KOSMIC workspaces perform different parts of the
analysis:

| Workspace | What you use it for |
|---|---|
| [Project](project/index.md) | Create the project, add datasets as studies, import their data and see their analysis status |
| [scRNA Analysis](scrna/index.md) | Quality-control and process one scRNA-seq or snRNA-seq study, identify cell populations and assign cell-type labels |
| [Differential Expression](de/index.md) | Compare two conditions within a selected cell type and investigate the resulting genes and pathways |
| [Meta-Analysis](meta/index.md) | Combine results from several studies to identify changes that are consistent across datasets |
| [Figures](figures/index.md) | Create and export figures from your analyses |

## What data do I need?

KOSMIC starts from single-cell or single-nucleus gene-expression data,
rather than raw sequencing reads such as FASTQ files.

The data should contain an expression matrix describing the number of
RNA transcripts detected for each gene in each cell or nucleus.
Depending on how the data were generated or downloaded, this may be
stored as an `.h5ad` file, a Seurat object, a 10x Genomics matrix or a
delimited count matrix.

KOSMIC can also retrieve suitable datasets directly from GEO.

For differential expression, KOSMIC requires raw integer gene counts
and information identifying the biological donor and experimental
condition associated with each cell. The intended design is a
comparison between two conditions within a cell type, with multiple
biological donors in each condition.

Human gene symbols can be harmonised to current HGNC nomenclature so
that datasets produced using different annotation releases can be
compared. Mouse datasets can also be analysed individually.

## Getting started

Install KOSMIC following the [installation guide](install.md). For a
new analysis, then begin in the [Project workspace](project/index.md).

Create a project for the biological question you want to investigate,
then add your first scRNA-seq or snRNA-seq dataset as a study. KOSMIC
will guide you through importing the expression data and preparing the
study for analysis.

As the study progresses, its status is shown in the Project workspace
and the *Next step* panel indicates which part of the analysis is
ready to be performed next.

Press **F1** from any KOSMIC screen to open the help page for that part
of the application. Terms are defined in the [Glossary](glossary.md).
