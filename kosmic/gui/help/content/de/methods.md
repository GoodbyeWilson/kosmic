# Choose Analysis Mode

Select between scoring (test specific pathways) or discovery (find what changed) mode.

## Scoring mode

Choose this if you have specific pathways or gene sets you want to test. You will select gene sets, explore pathway expression, run gene-level DE, then run pathway-level DE to score and statistically test each pathway.

## Discovery mode

Choose this if you want to find out which biological processes are affected. You will run genome-wide gene DE, then use enrichment analysis (GO, KEGG, Reactome, etc.) to identify over-represented pathways among significant genes.

## Switching modes

You can switch modes at any time by returning to this page. Gene DE results are preserved and reusable across both modes.
